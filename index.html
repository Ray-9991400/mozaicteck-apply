About MozaicTeck

MozaicTeck is a program that aims to provide people interested in the programming field with easy to learn courses on different programing languages. Whether you're a front-end, back-end or full-stack developer, you'll find courses on what you're interested in. Programs on offer include:

Front-end:

The front-end is the interface that end users interact with (i.e when you're using an app or browsing a webpage, the things that you see and use, that is the front-end and the person using it is the end user). Programming languages that deals with the front-end include HTML, CSS, JavaScript, etc.

Back-end:

This is the area that admins and developers see and use, it is not easily accessed by the end user. A good example of this is a schools database, in the database you have a section that students use and a section that only a few people in that school has access to, like when you want to check results, a student can only check his/her result or their friend's own if they have the pin, they cannot check every single student's result, that is something only the principal and some teachers can check. That part is the back-end. Programs that teach back-end include Phython, Node Js, etc.

AI Masterclass:

This program teaches you need to know about artificial intelligence.
